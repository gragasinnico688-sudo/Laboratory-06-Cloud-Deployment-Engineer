# Laboratory 05 — Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud storage and object storage. I learned about the differences between Block Storage, File Storage, and Object Storage. I also deployed a MinIO S3-compatible object storage server using Docker and created a bucket for storing a sample file.

## Objectives

- Understand the three main types of cloud storage.
- Compare Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access a cloud service through a web browser.
- Create an object storage bucket.
- Upload a file to the bucket.
- Document the deployment process using Markdown.

## Tools Used

- KillerCoda Playground
- Ubuntu Linux
- Docker
- MinIO
- Web Browser
- GitHub
- Markdown

## Skills Learned

This laboratory helped me understand how different types of storage are used in cloud environments. I practiced using Docker to deploy MinIO and learned how environment variables can be used to configure a container. I also learned how to access a service through a specific port, create an object storage bucket, and upload an object through a web interface.
